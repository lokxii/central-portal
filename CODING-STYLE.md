# Coding Style

You should always aim for low entropy in codebase.

You should always make the minimum amount of code change in each task.

You do not need to assume long term development. However, you should aim for
easy-to-understand, easy-to-maintain code even by human.

You should always analyse your changes to ensure correctness.

You should always analyse your code to check for security safeness. However you
do not need to analyse source code of depending library to ensure security.

For Javascript, since I want you to avoid typescript, You should use JSDoc for
typechecking
